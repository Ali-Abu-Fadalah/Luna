# Privacy

## Local information

Luna can store queues, ad names, notes, captured listings, image URLs, comparison inputs and interface preferences in the local Chrome profile. Clipboard actions happen only when you choose a copy control. Removing the extension removes its extension-storage data; keep any information you need elsewhere first.

## Website access

Capture tools read the page you choose. Image collection can request a selected HTTPS image from a built-in public vehicle-site host without sending cookies or credentials. Supported image formats and response sizes are checked. Image requests reject unapproved hosts, credential-bearing URLs, local-network targets and redirects.

The public build does not include a private spreadsheet reader, writer deployment, catalog transport, internal-site connection or AI provider transport. No organization endpoint, spreadsheet identifier, account credential, API key or captured work dataset is bundled.

## Diagnostics

Safe diagnostic reports contain version information and bounded status codes and timestamps. They omit ad content, full URLs, keys and credentials. Review any report before sharing it publicly. Never post Chrome storage exports, account sessions, real company rows or customer details in an issue.

## Limits

Local Chrome storage is not encrypted by Luna and is not a secret vault. Device access, browser-profile backups and other authorized software can expose local information. Use fictional data when demonstrating the public edition.
